# 0.53 Beacon

Die vier ausgewählten Volt-05-Pistolen stehen als K05, L05, M05 und N05 im Register. Der Serienbau ist über `python -m formgen.pipeline --series Volt-05` verfügbar.

Die lokal freigegebenen Kit-Dateien liefern den Vergleich für die Registermodelle. Zwei getrennte Serienausgaben ermöglichen zusätzlich den Bytevergleich der Modellblätter, Ansichten, Specs und Prompts.

Der Pull Request baut auf dem Volt-04-Branch auf. Tag und Release stehen bis zur Nutzerfreigabe aus. [Pull Request für Volt-05](https://github.com/ffunkfabian-hash/cubeescape-formgenv2/pull/65)

**Urteil**

Der Nutzer hat Service, Patrol, Ranger und Field freigegeben. Der unabhängige Richter hat die Registrierung freigegeben. Alle vier Kits stimmen mit der Auswahl überein. Die vollständige Projektprüfung war grün (3531 s).
