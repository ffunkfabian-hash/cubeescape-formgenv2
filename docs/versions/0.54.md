# 0.54 Mica

Die vier ausgewählten Volt-06-Maschinenpistolen Service, Patrol, Ranger und Field sind als K06, L06, M06 und N06 im Register verfügbar. Der Serienbau läuft über `python -m formgen.pipeline --series Volt-06`.

Die freigegebenen Kit-Dateien dienen als Referenz. Der Serienbau in zwei Ausgabeordnern erlaubt einen zusätzlichen Bytevergleich für Ansichten, Modellblätter, Specs und Prompts.

Der Pull Request baut auf dem Volt-05-Branch auf. Tag und Release stehen bis zur Nutzerfreigabe aus. [Pull Request für Volt-06](https://github.com/ffunkfabian-hash/cubeescape-formgenv2/pull/67)

**Urteil**

Der Nutzer hat alle vier Modelle gewählt. Der unabhängige Richter hat die Registrierung freigegeben. Die vier Kits wurden mit der freigegebenen Auswahl abgeglichen. Die vollständige Projektprüfung war grün (2291 s).
