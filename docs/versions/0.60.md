# 0.60.0 „Gantry“ (28.11.2026) – Linie T als ein Block nach main

Branch `claude/formgenv2-0.60-gantry`, Basis die abgeglichene Spitze der Kette Linie T (0.40 Moraine). Merge und Tag nur mit Ja des Nutzers.

Auftrag (Nutzer, 28.11.2026): alle offenen Versions-PRs auf den Stand von main bringen und mergen; die Linie T „als ein Block als 0.60“,
weil keine ihrer Stufen die Version über main heben kann (`merge-check` verlangt eine höhere Nummer als main).

## Ergebnis

- **Linie T in main:** die 14 Versionen 0.24 Crossbeam (BT01 Trestle), 0.26 Lamella (BT02 Vesper), 0.27 Plume (BT03 Heron),
  0.29 Strata (BT04 Cairn), 0.30 Imprint (Cairns Ladesiegel), 0.31 Pinion (BT05 Swift), 0.32 Windward (BT06 Tern), 0.33 Quill (BT07 Lark),
  0.34 Skiff (BT08), 0.35 Avocet (BT09), 0.36 Calyx (BT10), 0.37 Plover (BT11), 0.39 Filament (BT12) und 0.40 Moraine (BT13) kommen
  unverändert in einem Merge. Ihre Einträge in CHANGELOG, README und `docs/versions/` behalten Nummer und Inhalt, ebenso die
  `since`-Felder im Register. Blatt-Spec `formgenv2/weapon-sheet-spec` Version 4 (eigenständige Außenform) mit Migration 3 → 4 aus 0.24.
- **Abgleich mit main (0.42.2 bis 0.59):** Quellhash der Pipeline-Blätter (`PIPELINE_SHEETS`) liegt in `extended.source`, weil main
  `source_of` auf Pfade umgestellt hat (ZERO, DaVinci). Der Schnitt-Test aus 0.38 (`test_bore_keeps_its_length_in_every_line`)
  prüft nur Linien, die BASIC-02 umformen; die Gegenprobe `test_only_own_architectures_skip_the_bore` hält fest, dass nur Linien mit
  eigener Architektur ohne BASIC-02-Laufkanal übersprungen werden.
- **Abgelöst:** PR 26 (0.16 Trestle) ist in 0.24 aufgegangen und wurde geschlossen; die PRs der 14 Stufen werden mit Verweis auf
  diesen PR geschlossen, ihre Branches bleiben als Versionsregister.
- **Prüfung:** `./check` an der abgeglichenen Spitze vor dem Volt-Merge 960 Tests OK (der Schnitt-Test danach gezielt grün).

## Lehren

- Gestapelte Versionsketten, die länger als ein paar Tage offen bleiben, verlieren ihre Nummern: sobald main eine höhere Version
  trägt, lässt `merge-check` keine Stufe mehr einzeln zu.
