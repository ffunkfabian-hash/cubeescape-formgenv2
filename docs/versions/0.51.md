# 0.51 Relay

Volt-04 umfasst die vier ausgewählten Handfeuerwaffen Service, Patrol, Ranger und Field. Die Blattkennungen K04, L04, M04 und N04 entsprechen der freigegebenen Galerie. Der Serienbau ist über `python -m formgen.pipeline --series Volt-04` verfügbar.

Die Referenzen für Specs, Prompts und Bilder wurden aus zwei getrennten Serienausgaben abgeglichen. So lassen sich die vier gewählten Modelle auch nach späteren Änderungen an Generator und Darstellung einzeln prüfen. Das lokale Testpaket enthält 79 Dateien.

Der Pull Request baut auf dem Volt-03-Branch auf. Tag und Release stehen bis zur ausdrücklichen Freigabe aus. [Pull Request für Volt-04](https://github.com/ffunkfabian-hash/cubeescape-formgenv2/pull/64)

**Urteil**

Die unabhängige Prüfung bestätigt, dass die vier registrierten Kits mit der freigegebenen Galerie übereinstimmen. Der erste Richterdurchgang forderte Ergänzungen im Versionsbericht. Der zweite Richterdurchgang hat die Änderung freigegeben. Die vollständige Projektprüfung war grün (1634 s).
