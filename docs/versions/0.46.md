## Lehren

- Eine neue Waffe der Familie braucht eine eigene Hülle, nicht nur ein eigenes Detail: Fenster, Ringschaft und Versatz lagen gegen EA01 bei
  0,82–0,88, erst die Massenverteilung (hoher Rahmen, schlanke Arme) brachte 0,79. Die Kanon-IoU in der Skizzenphase spart Renderrunden.
- Ein Renderwerkzeug, das eine ID aus einem Register ableitet, gegen die gerenderte Quelle prüfen: `subject()` lieferte für `z01` still EA01.
- Die Kanon-Dreiecke (`variety.triangles`) tragen keine Bool-Schnitte. Negativraum an Querprofilen deshalb am ausgewerteten Netz
  (`geom.evaluate`) messen; die Kanon-IoU zählt Durchbrüche als Fläche.
